# 课业待办 · CampusTask

面向校园场景的**任务管理 Web 应用**，使用原生 **HTML + CSS + JavaScript** 实现，无需安装任何依赖，双击 `index.html` 即可在浏览器中运行。

## 运行方式

1. 直接用浏览器（推荐 Chrome / Edge）打开 `index.html`。
2. 或在本目录启动任意静态服务器，例如 `python -m http.server 8080`，访问 `http://localhost:8080`。

## 功能一览

| 模块 | 功能 |
| --- | --- |
| 今日一屏 | 今日课表（课程/碎片/空闲）+「现在做」推荐 + 今日必做 + 出口，单页内完成所有操作 |
| 现在做什么 | 按「逾期 > 截止临近 > 优先级 > 陈旧度」打分推荐一个任务，附一句人话理由，可「换一个」或直接去专注 |
| 今日课表 | 只展示课程与空闲结构，连续 ≥2h 空隙标「空闲」，<2h 标「碎片」，课程前后自动留缓冲 |
| 今日必做 | 只显示 24 小时内截止的任务，最多 5 条折叠，逾期置顶，已完成折叠在底部 |
| 快速录入 | 输入一句话即可添加：`明天下午3点交实验报告 高优先`、`今晚8点 复习高数`、`周五前交设计稿 紧急` |
| 每个任务独立提醒 | 每个任务可单独设置提前提醒（不提醒 / 15 分钟 / 30 分钟 / 1 小时 / 3 小时 / 1 天），到达时间弹出提醒与桌面通知 |
| 下一步动作 | 大任务可填一个「下一步」小动作，列表优先显示，解决「大任务不启动」 |
| 建议 / 收工 | 必做全部完成时给出建议任务；收工仪式对剩余任务三选一（顺延明天 / 移到本周 / 放弃） |
| 番茄钟 | 专注页番茄钟，支持自定义专注时长，时间戳精确计时 |
| 课表管理 | 今日一屏内折叠展开，录入整周课程 |
| 全部任务 | 完整任务列表，分组管理、新建、编辑、删除、批量操作 |
| 本地持久化 | localStorage 自动保存，刷新不丢失；旧数据自动迁移 |

## 目录结构

```
大作业/
├── index.html          # 页面入口
├── css/style.css       # 全部样式（双主题、响应式、玻璃拟态）
├── images/             # 背景风景图（本地图片，离线可用）
│   ├── bg-main.jpg     # 全屏背景
│   └── bg-hero.jpg     # 今日一屏横幅
├── data/quotes.json    # 每日一言数据（fetch 演示）
├── js/
│   ├── utils.js        # 命名空间与工具函数
│   ├── storage.js      # 数据持久化层（localStorage + 校验/迁移）
│   ├── model.js        # 任务模型、预设视图、周历与计划算法
│   ├── pomodoro.js     # 番茄钟
│   ├── router.js       # 哈希路由（SPA）
│   ├── view.js         # 视图层（表格、批量、时间表、计划）
│   └── app.js          # 入口（初始化、时钟、提醒、示例数据）
└── README.md
```
